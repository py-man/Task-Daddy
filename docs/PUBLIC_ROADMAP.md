# Task-Daddy Public Roadmap

This roadmap is safe to publish. It reflects product direction without exposing internal operating notes, customer context, or private release process.

## Now

- Core board workflow hardening
  - faster task create/edit flows
  - stronger mobile board interactions
  - drawer reliability and fewer state desync issues
- Security and account controls
  - MFA enrollment and recovery flows
  - session visibility and revocation
  - safer password reset and admin controls
- Backup and restore confidence
  - downloadable exports
  - retention controls
  - clearer restore validation

## Next

- Integration depth
  - GitHub Issues and Projects
  - GitLab Issues
  - Slack and Microsoft Teams actions
  - improved Jira and OpenProject diagnostics
- Smarter planning support
  - workload suggestions
  - board health summaries
  - deterministic automation rules with preview-before-apply
- Import and migration paths
  - better board imports
  - clearer field mapping
  - safer repeatable sync behavior

## Later

- Calendar ecosystem
  - Google Calendar
  - Outlook / Microsoft 365 Calendar
  - stronger reminder delivery options
- Workflow extensions
  - Apple Shortcuts
  - Zapier / Make style automation bridges
  - more external event hooks
- Knowledge and reporting
  - research/context packs
  - richer reports and operational summaries

## Release Principles

- No private production data in demo or seed content.
- No internal-only backlog, operator memory, or customer-specific notes in the public repo.
- Every shipped feature must keep tests and operator instructions current.
